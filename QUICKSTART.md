## 🏃 Quick Start

### 1. Install Dependencies

```bash
cd D:\UnifiedAi\backend
pip install --user -r requirements.txt
```

### 2. Start the Server

**Option A: Use START.bat**
```bash
cd D:\UnifiedAi
START.bat
```

**Option B: Manual Start**
```bash
cd D:\UnifiedAi\backend
python run.py
```

Server will run on: **http://localhost:10000**

### 3. Open the Frontend

Open `F:\UnifiedAi\frontend\index.html` in your browser.
