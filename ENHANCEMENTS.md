### ActivatePrime - Emotional Intelligence
- `POST /api/activateprime/analyze` - Full emotional analysis

- `POST /api/activateprime/glyph/encode` - Text to glyphs
- `GET /api/activateprime/glyph/dictionary` - Full glyph reference
- `GET /api/activateprime/personality` - Current personality state

### Semantic Search
- `POST /api/search/index` - Index a document
- `POST /api/search/query` - Semantic search
- `POST /api/search/similar` - Find similar documents
- `GET /api/search/stats` - Search statistics
